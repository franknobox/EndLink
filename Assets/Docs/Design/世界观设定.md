# 世界观设定


### 近未来科幻\+虚拟网络空间

不以设定为核心导向，

仅作为游戏各方面设定展开的基础，

为 角色/战斗/场景/UI与视觉风格 等 提供一个轻量的、合理的、扩展性强的 **背景解释**

## 背景概要：

近未来的世界，虚拟的网络空间高度发达，人类大部分时间生活在其中

> 类似《头号玩家》中的 “绿洲” 游戏
> 
> 

但有一部分区域因不明原因出现了污染与崩塌，导致大量人类遭受损伤

于是某一方组织派派遣 AI智能体 小队，进入调查，玩家操控其中的一个ai作为主角。



> 参考《尼尔：机械纪元》派遣人造人前往地球的设定
> 
> 



## 核心概念：

**【ENDLINK】**

全称 Endlink Protocol 终端协同链路协议 / 终链协议

解释：智能体之间的高同步协作协议，是一种让多个 AI 智能体共享感知、算力、战斗指令和攻击窗口的同步协议。



【智能体】

智能体是指能够感知环境并自主采取行动以实现特定目标的实体。这一概念最早由马文·明斯基提出，他认为某些问题可经由社会中的一些个体经过协商后解决，这些个体就是智能体。并且他还认为智能体具备社会交互性和智能性。

AI Agent（人工智能智能体）是一种通过使用可用工具设计工作流来自主执行任务的系统。通过大语言模型理解需求、规划目标并执行任务，具备**自主感知、推理、规划、记忆和使用工具**的能力，能够自动化执行完成复杂任务的系统，其核心特征为主动思考与跨工具操作能力。

该概念起源可追溯至亚里士多德时期对自主实体的哲学探讨，现代技术雏形始于20世纪50年代图灵测试提出的人工智能实体概念。

以上是一些AI知识的概念，具体到游戏中，可以有以下的一些设定作为参考：

角色设定方面

> 类似一个人的种族、职业、星座什么的
> 
> 


智能体角色可以先归纳为六个开发维度：

|维度|核心含义|开发作用|
|---|---|---|
|智能体类型|角色的基础定位，类似职业、种族或用途分类。|用于区分战斗型、支援型、工程型、研究型等角色方向，后续可影响 AI 倾向、技能和队伍职责。|
|核心模型 Model|角色的内在“大脑”，决定思维方式、性格倾向和能力底层逻辑。|可作为角色能力、成长曲线、战斗风格、台词行为和角色个性的设定来源。|
|架构 Harness|角色的执行外壳，决定身体结构、外观轮廓和动作实现方式。|对应模型、动画、移动方式、碰撞形态、武器接口和特殊运动能力。|
|工具 Tools|外接武器、设备或功能模块。|对应具体武器、技能、攻击动作、命中盒和特效来源。|
|记忆 Memory|角色经历、任务记录和个人痕迹。|可用于养成、剧情、角色细节、差异、旧任务反应和特殊被动。|
|协议权限 Authority|智能体在 Endlink 协议中的权限等级。|可用于解释主控权限、队友响应权、连携资格、技能解锁和系统等级限制。|

当前工程阶段不需要立刻把这些维度全部做成独立系统。短期可以把它们作为角色数据设计的概念边界保留；等后续制作 `CharacterStats`、角色数据资产、技能配置和队友 AI 行为时，再逐步决定哪些维度需要落到实际字段里。







## 敌人概念

### 异常实体 Anomalous Entity

**大意：** 所有敌人的统称。

在污染区所遭遇到的敌人，它们并不一定有完整人格或核心模型。

### 异常程序 Aberrant Program

**大意：** 指一切小怪。

污染区中最常见的敌人。它们通常没有完整人格，也没有核心模型。

**细分：**

- **游离态**
  - 无实体框架。
  - 无法受到结构伤害，只能被运行伤害攻击。
  - 工程中对应 `AberrantProgramForm.FreeState`。
- **显壳态**
  - 有实体框架外壳。
  - 可以受到结构伤害与运行伤害。
  - 工程中对应 `AberrantProgramForm.ManifestedShell`。
  - 错误本不会攻击人，直到某个存在，教会了它们敌意。

### 受污染的智能体 Delinked Agent

**大意：** 敌对的，与玩家同类型的角色。

他们也曾接入过协议。

在某个事件之后，它们的记忆与判断被污染，敌我不分，曾经的任务目标被扭曲。

某个本拥有名字的个体，被污染后留下的残影。

### 失控系统单元 Rogue System Unit

**大意：** BOSS。

一个区域仍在运行的意志，只是已经忘记了自己要保护什么。
