## 标签反应

标签反应工程上先按“触发条件 + 反应效果列表”理解：

| 反应效果类型 | 用途 |
| --- | --- |
| 生成标签 | 生成新的高级标签，例如 2 级反应标签。 |
| 移除标签 | 消耗参与反应的标签，或清除某些状态。 |
| 造成伤害 | 反应触发时造成一次额外伤害。 |
| 扩散标签 | 把某个标签传播到周围目标。 |
| 控制效果 | 冻结、打断、定身、击晕等。 |
| 资源变化 | 增加连携值、极限技能量或其他战斗资源。 |
| 自定义事件 | 为特殊反应预留入口。 |

## 小队作战

### Link Down / 链接中断

队友血量归零后，不直接消失，也不进入传统意义上的“死亡”状态，而是进入 **Link Down / 链接中断** 状态。

| 项目 | 设定 |
| --- | --- |
| 触发条件 | 队友生命值归零。 |
| 状态定义 | 队友与终链协议暂时断开，无法继续参与当前战斗。 |
| 表现方向 | 模型保留在原地，呈漂浮、半透明、低活性状态；后续可以附加专用 UI、提示标识、协议断线特效或音效。 |
| 战斗影响 | 队友无法参与攻击、技能、连携、助战、跟随等战斗行为；无法作为敌人目标；在战斗逻辑上等同于暂时从场上消失。 |
| 救助方式 | 玩家靠近链接中断的队友后，长按交互进行救助。救助完成后，队友恢复部分生命值，并重新接入终链。 |
| 恢复结果 | 队友重新成为有效小队成员，恢复目标有效性、跟随、助战和连携参与资格。 |

实现备注：

- 链接中断不是普通死亡，不应按敌人死亡那样销毁或隐藏角色根物体。
- 链接中断期间，队友应保持视觉存在，但 `CombatTarget` / AI / 敌人索敌应视其为不可选、不可攻击、不可参与战斗。
- 救助行为后续可以独立做成玩家交互动作，避免把救助逻辑塞进生命组件本身。

### EndLink Ultimate / 终链奥义

“奥义”是终链协议当中的高阶技能。主角作为小队协议中的核心承载节点，小队在战斗中触发连携时，会让智能体之间的感知、算力和攻击窗口发生短暂同步。

这些同步行为会产生“同步回流”，提升协议中的协同率。协同率是终链奥义的充能资源。

| 项目 | 设定 |
| --- | --- |
| 技能定位 | 全队大招，属于终链协议中的高阶技能，也可理解为 LB 极限技。 |
| 核心承载 | 主角是小队协议中的核心承载节点，奥义释放时由主角作为最终执行端。 |
| 充能资源 | 协同率。协同率代表小队成员之间的感知、算力和攻击窗口同步程度。 |
| 充能来源 | 在终链窗口内释放连携技能。每个连携技能可以配置自己的协同率收益，释放成功后产生同步回流并提升协同率。 |
| 释放条件 | 协同率达到 100%，视为协同编排完成。 |
| 释放目标 | 第一版程序实现不要求目标；后续可以设计为时停、全局演出、全屏效果或其他不依赖单体目标的高阶技能。 |
| 释放结果 | 核心智能体调用高阶技能，释放终链奥义。当前程序第一版先只处理协同率满值、可释放和消耗，具体表现与效果待定。 |

第一版规则可以理解为：**触发协议反应 -> 打开终链窗口 -> 释放连携技 -> 提升协同率 -> 协同率满 100% -> 释放终链奥义**。
